OPEN HYDRA

1. Find a section

Use the tabs at the top of HYDRA to open Home, Curse Head, Health Head, Third Head, HYDRA AI, Companionship, HYDRA OS, or Manual.

2. Add a device shortcut

Select ADD TO DEVICE when the browser offers installation. If there is no prompt, use the browser menu and choose Install app or Add to Home Screen. On iPhone or iPad, use Safari's Share menu and choose Add to Home Screen.

3. Analyze an image

Open Health Head, choose an image in Battlebot Scan, configure a Pollinations vision key, and select ANALYZE. The selected image is sent to Pollinations for analysis. Do not upload sensitive images. Results require a valid key and an available service.

4. AI availability

AI chat and cloud-generated responses require a reachable AI relay. GitHub Pages hosts static files only, so these features may show offline until a backend relay is configured. The app's other interface sections remain available.
